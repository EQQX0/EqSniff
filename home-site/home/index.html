Questions

Does any of my traffic leave my computer? No — capture, filtering and host detection all run locally; your account only stores the IPs and filters you choose to save.

What does “likely hosting” mean? EqNetwork watches which address sends and receives the most sustained traffic in a session and marks that one with a crown — a strong signal, not a certainty.

Do I need administrator rights? Yes, briefly — Windows requires elevated access to read raw packets from a network adapter.

Which adapters does it support? Any adapter Windows exposes to Npcap, including Wi-Fi and Ethernet; the installer sets up the capture driver for you.

Can I open a capture I saved earlier? Yes — open a saved file the same way you’d start a live capture, and every filter still applies.

What happens to my saved IPs if I reinstall? Nothing — they live in your account, not on the machine, so signing in on a fresh install brings them back.

Is there a Mac or Linux build? Not yet — EqNetwork is Windows-only for now, built directly against the Windows capture APIs.

How do I sign in on a second computer? Install the app, choose Sign in, and use the account you created at sniff.eqqx2.com/signup.
