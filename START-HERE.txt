EqSniff: where everything is
============================

THIS FOLDER (C:\Users\Admin\Desktop\EqSniff)
  desktop\          the app (Tauri + Rust + React). Run commands from here.
    src\            screens and code (React)
    src-tauri\      Windows side (Rust): capture, scan, filters, VPN
    tests\          filter tests         (npm test)
    src-tauri\tests Rust tests           (cargo test --tests)
  replica\          notes on the feature plan
    scope.md        what the app is and is not
    features.csv    every feature and whether it is built
    unbuilt.md      what is missing and why
    build-log.md    what was done, round by round
    reference-app-ui-notes.md   what the reference app's screens showed
  release\          installer, portable zip, certificate (not in git)
  README.md         overview
  update.json       the file the update check reads
  _archive\         the old dropped web dashboard
  .git\             history. Remote: https://github.com/EQQX0/EqSniff (private)
